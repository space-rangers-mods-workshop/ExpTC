### Summary

Warning! Untranslated staff! Adds a new base type - Technology Center and some new weapon akrins

---

## 📖 Description

The Technology Center offers:
- Equipment Upgrades
- Closing and opening slots
- Change susceptibility to a particular type of damage
- Lifeboat Installation
- Hardware firmware (hardware upgrade)
- Improve probes
- Rollback improvements (removing improvements from equipment)
- Adds the ability to mine and profitably sell valuable minerals
